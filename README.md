# embedhash

[![Go Reference](https://pkg.go.dev/badge/github.com/hcarriz/embedhash.svg)](https://pkg.go.dev/github.com/hcarriz/embedhash)
[![Go Report Card](https://goreportcard.com/badge/github.com/hcarriz/embedhash)](https://goreportcard.com/report/github.com/hcarriz/embedhash)

`embedhash` finds the files selected by Go `//go:embed` directives and
generates a deterministic Go map containing a content hash for each file. The
map can be compiled into the same package and used for cache keys, ETags, or
change detection.

## Requirements

- Go 1.24 or newer for source compatibility
- A currently supported, fully patched Go release for production use

Go 1.24 is the compatibility floor declared by this module. Raising or lowering
that floor is treated as a consumer compatibility change.

## Installation

Install the command:

```sh
go install github.com/hcarriz/embedhash/cmd/embedhash@latest
```

Or add the library to another module:

```sh
go get github.com/hcarriz/embedhash
```

## Command-line usage

Suppose package `assets` embeds a directory:

```go
package assets

import "embed"

//go:embed static
var files embed.FS
```

Run `embedhash` with an explicit Go package pattern:

```sh
embedhash -hash sha256 -out embedhashes.go -var EmbeddedHashes ./assets
```

This writes `assets/embedhashes.go`:

```go
// Code generated by embedhash, DO NOT EDIT.
package assets

var EmbeddedHashes = map[string]string{
	"static/app.css": "0466c472...",
	"static/app.js":  "93f0d05c...",
}
```

The command accepts these flags:

| Flag | Default | Meaning |
| --- | --- | --- |
| `-hash` | `md5` | Hash algorithm: `md5` or `sha256` |
| `-out` | `embedhash.go` | Generated filename in each matching package |
| `-var` | `HashesForEmbedded` | Generated map variable name |
| `-dry` | `false` | Print each destination and its generated source without writing |

Package patterns use the syntax accepted by the Go toolchain, so patterns such
as `./assets` and `./...` are supported. A package with no embedded files does
not produce a result. Existing destination files are replaced by the command;
use `-dry` to inspect destinations and generated source first.

## Library usage

The library separates discovery from writing. `New` returns one `Result` per
matching package, and each result can be rendered with `Result.Save`:

```go
package main

import (
	"crypto/sha256"
	"log"
	"os"

	"github.com/hcarriz/embedhash"
)

func main() {
	results, err := embedhash.New(
		"./assets",
		embedhash.Hasher(sha256.New()),
		embedhash.OutputFileName("embedhashes.go"),
		embedhash.OutputVarName("EmbeddedHashes"),
	)
	if err != nil {
		log.Fatal(err)
	}

	for _, result := range results {
		if err := save(result); err != nil {
			log.Fatal(err)
		}
	}
}

func save(result *embedhash.Result) error {
	f, err := os.Create(result.Filename)
	if err != nil {
		return err
	}

	if err := result.Save(f); err != nil {
		_ = f.Close()
		return err
	}

	return f.Close()
}
```

Library defaults differ from the command only in the output filename: `New`
uses `embedhashes.go`, while the command uses `embedhash.go`.

## Behavior and security

- Map keys are paths relative to the package directory and always use `/` as
  the separator.
- Generated entries are sorted by path, so unchanged input produces stable
  source output.
- `OutputFileName` uses only the supplied path's base name. Generated files
  always stay in the matching package directory.
- Discovery uses `go/packages`; the target packages and their module
  dependencies must be loadable by the Go toolchain.
- There is no built-in limit on the number or total size of embedded files.
- The default MD5 digest is suitable for non-adversarial change detection, not
  collision resistance, authentication, or security-sensitive integrity
  checks. Select SHA-256 when collision resistance matters. A plain digest does
  not authenticate content.
- A custom `hash.Hash` is reset and reused while `New` runs. Do not use that
  same hasher concurrently elsewhere.

The generated map is an ordinary mutable Go map. Concurrent reads are safe only
while no goroutine writes to it.
